An EMA trend-rider bot that trades Coinbase Wrapped BTC (cbBTC) on 1-minute bars with $1,000 of paper money: it buys in full when the 12-bar EMA crosses above the 48-bar EMA and holds with a 2.5% trailing stop, trading rarely because 1-minute noise plus ~40 bps of round-trip cost punishes churn.

## Run it

```sh
node main.ts
```
